Usage Disclaimer

SoulX-Singer is intended for academic research, educational purposes, and legitimate applications.

Please note:

  • Respect intellectual property, privacy, and personal consent when generating singing content.
  • Do not use the model to impersonate individuals without authorization or to create deceptive audio.
  • The developers assume no liability for any misuse of this model.

The Soul AI Lab advocates for responsible development and use of AI. For ethics or misuse concerns, contact the team directly.
